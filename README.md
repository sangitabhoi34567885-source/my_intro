# 🌐 Personal Portfolio Website

## 📌 About the Project

This is a simple **Personal Portfolio Website** created as a beginner project using **HTML and CSS**.

The website introduces me, displays my skills, provides information about me, and includes contact details.

## ✨ Features

* 🏠 Home section
* 👩‍💻 About Me section
* 💻 Skills section
* 📩 Contact section
* 🖼️ Profile picture
* 🧭 Navigation menu
* 🎨 Simple and clean CSS design
* 📱 Beginner-friendly layout

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure of the webpage.
* **CSS3** – Used to style and design the webpage.

## 📂 Project Structure

```text
Portfolio/
│
├── index.html
├── style.css
├── myphoto.jpg
└── README.md
```

## 🚀 How to Run

1. Download or clone this project.
2. Open the project folder in VS Code.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in a web browser.
5. You can also use **Live Server** in VS Code.

## 🎯 Purpose

The purpose of this project is to practice the basics of:

* HTML tags
* CSS properties
* Navigation links
* Page sections
* Flexbox
* Images
* Buttons
* Basic webpage design
